MCP Trust Lab

Turn an unfamiliar MCP configuration into a concrete human-review plan. Inspect launch commands, credential handling, remote endpoints and declared tool capabilities—without running a server.

Local-only heuristic analysis. No uploads, storage, network requests or code execution. Prefer redacted inputs. A clean report is not proof of safety.

What the rules do—and do not—tell you

Rules flag literal credentials in environment/header fields, shell launchers, unpinned package launchers, broad filesystem/scopes, insecure remote URLs and potentially destructive tool names or annotations. Tool-description checks are simple phrase matches, not a prompt-injection detector.

The review score starts at 100 and subtracts severity weights (critical 35, high 20, medium 8, low 2). It is a triage aid, not a security rating. Configurations and annotations cannot establish a server's real behavior, provenance or authorization. Review source code, sandbox the process, verify package integrity and enforce permissions outside this tool.
